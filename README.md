# Dickens Wealth Management — Client Intake Form

Professional new-client intake form for the team at **Dickens Wealth Management**.

## Live App

Once GitHub Pages is enabled, the form will be available at:

**https://willyrelwitten.github.io/client-intake/**

## How to use

1. Open the live link (or open `index.html` locally)
2. Fill out the form with the client
3. Click **Generate 1-Page PDF**
4. The PDF downloads automatically — save it to the client file

## Features

- Clean, mobile-friendly web form matching the original paper intake
- Generates a professional single-page PDF
- No backend / no login required
- Works offline once loaded

## For a cleaner professional URL

You can point a custom domain (recommended) such as:

- `intake.dickenswm.com`
- `clients.dickenswm.com`

Instructions: GitHub repo → **Settings** → **Pages** → Custom domain.
